# 추억앨범 다이어리

> 친구들과의 약속·여행·일상을 방 하나에 모아, 약속 잡기부터 정산과 사진 추억까지 한 번에 남기는 공유 앨범 앱 (MVP)

단톡방에서 날짜를 잡고, 지도 앱으로 장소를 보내고, 송금 앱으로 정산하고, 사진은 대화에 묻혀 사라지는 일을 **방 하나**로 끝냅니다.
남긴 사진은 **캘린더 칸**과 **여행 지도**를 채워, 다시 꺼내 보는 추억이 됩니다.

- 📄 기획 문서: [`추억앨범 다이어리 PRD v1.0.md`](./추억앨범%20다이어리%20PRD%20v1.0.md)
- 🖥️ 앱 파일: [`추억앨범 다이어리.html`](./추억앨범%20다이어리.html)

## 주요 기능

| 탭 | 기능 |
| --- | --- |
| 💬 **방** | 일상 방. 상태 이모지 + 한 줄 + 사진 1장으로 지금 뭐 하는지 공유 |
| 🍻 **모임** | 약속 카드(날짜·시간·장소·D-day), 정산, 사진 추억 기록 |
| 🗺️ **여행** | 국내 17개 시·도 / 해외 세계 지도. 다녀온 곳이 사진으로 채워지는 **지도 도장** |
| 📅 **캘린더** | 사진을 남긴 날은 그 사진이 달력 칸을 채움. 날짜를 눌러 바로 사진 붙이기 |
| 🙂 **마이** | 참여한 방·추억 남긴 날·지도 도장 수, 내 추억 사진첩 |

### 방 상세 (모임·여행 공통)
- **초대**: 🔗 버튼으로 초대 문구 복사 → 단톡방에 붙여 넣으면 친구가 링크로 들어와 ‘참여하기’
- **정산**: 항목·금액·낸 사람·나눌 사람 입력 → 최소 송금 횟수로 “누가 누구에게 얼마” 자동 계산, ‘보냈어요’ 체크
- **추억 기록**: 사진 최대 4장 + 140자, 날짜별 폴라로이드 카드. 여행은 Day 1·2·3으로 표시

## 사용 방법

### 1. 바로 열어 보기 (체험 모드)
`추억앨범 다이어리.html`을 다운로드해 브라우저로 열면 됩니다. 설치나 서버가 필요 없습니다.
이 모드에서는 데이터가 **그 기기의 브라우저에만** 저장됩니다.

### 2. 친구들과 함께 쓰기 (공유 모드)
claude.ai 아티팩트로 열면 방·기록·정산이 서버에 저장되고, 같은 방 멤버에게 실시간으로 보입니다.
친구가 기록하거나 사진을 올리려면 페이지 공유 메뉴에서 **‘참여자(Contributor)’ 이상** 권한이 필요합니다.

### 3. 처음 써 보기
1. **모임** 탭의 ＋ 버튼으로 방을 만들고 날짜·장소를 적습니다.
2. 방 안의 🔗 버튼으로 초대 문구를 복사해 단톡방에 보냅니다.
3. 모임이 끝나면 **정산** 탭에 비용을, **추억 기록** 탭에 사진과 한 줄을 남깁니다.
4. **캘린더**와 **여행** 탭에서 사진으로 채워진 달력과 지도를 확인합니다.

> 처음이라면 빈 화면의 **‘예시 방으로 둘러보기’** 버튼으로 연습용 방을 만들어 볼 수 있습니다.

## 기술 구성

| 항목 | 내용 |
| --- | --- |
| 형태 | 단일 HTML 파일 (HTML · CSS · 바닐라 JavaScript, 외부 라이브러리 없음) |
| 저장 | 공유 모드: 아티팩트 공유 DB · 체험 모드: 브라우저 localStorage |
| 사진 | 업로드 전 기기에서 긴 변 1,600px JPEG로 축소 |
| 지도 | 국내: 통계청 2013 시·도 경계 · 해외: Natural Earth 1:110m (SVG 경로로 내장) |
| 화면 | 모바일 우선, 다크 모드 지원 |

### 데이터 구조

```
rooms/{roomId}                  방 정보 (종류, 제목, 날짜, 장소, 지역, 멤버, 대표 사진, 정산 완료 표시)
rooms/{roomId}/notes/{id}       추억 기록 · 일상 상태 (작성자, 날짜, 글, 사진, 이모지)
rooms/{roomId}/expenses/{id}    정산 항목 (항목명, 금액, 낸 사람, 나눌 사람)
data/users/{me}/stamps          지도 도장 (나만 보는 개인 데이터)
```
