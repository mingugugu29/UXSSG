# 기록 레시피 MVP

기록을 안 하던 사람도 **질문 하나에 한 줄**로 시작하게 만드는 기록 앱의 클릭 프로토타입입니다.

## 실행 방법
`index.html` 파일 하나로 동작해요. 브라우저로 열기만 하면 됩니다. (설치 필요 없음)
- 여행 도장깨기의 전국 지도는 인터넷에서 지도 데이터를 불러와요. 오프라인이면 칸 형태 도장판으로 대신 보여요.

## 화면 구성 (탭 4개)
- **오늘의 한 줄**: 질문에 한 줄을 써야 다른 사람들의 답이 열려요
- **레시피**: 기록 포맷 22개 (초간단·하루·감정·회고·리뷰·여행·친구랑), 질문형으로 바로 쓰기
  - **여행 도장깨기**: 전국 17개 시·도 지도 조각을 내 사진으로 채우기
- **교환일기**: 친구 답 잠금 해제, 반응·댓글, 콕 찌르기, 내일 질문 내기, 릴레이 노트
- **내 기록**: 쌓인 기록, 이번 주 기록일, 연속 기록

## 참고
- 다른 사람들의 답, 친구 데이터, 참여자 수는 시연용 예시 데이터예요.
- 기록은 내 브라우저에만 저장돼요.
