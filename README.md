# UXSSG

UX/UI 프로젝트 작업 저장소입니다. 이 브랜치(`monit-mvp`)는 **MONIT(모닛)** 프로젝트입니다.

## MONIT (모닛)

> **함께한 순간이, 오래 남는 추억이 되도록.**
> 친구들과 놀러간 장소가 지도 위에 **추억 사진 섬네일 마커**로 쌓이는 프라이빗 소셜 라이프로그 서비스

약속을 만들고 친구들과 사진을 함께 모으면, 다녀온 장소가 지도에 사진 섬네일 핀으로 남습니다. 전국을 여행했다면 줌아웃했을 때 지역별로 묶여 보이고, 지역을 누르면 그 안의 장소 핀이 펼쳐집니다.

### 핵심 아이디어

- **약속 기반 기록:** 확정된 약속이 곧 공동 추억 공간이 됩니다.
- **지도 위 추억:** 장소마다 대표 사진이 섬네일 마커로 뜨고, 방문 횟수가 배지로 표시됩니다.
- **프라이빗 기본값:** 초대한 멤버만 볼 수 있고, 호스트 승인 후 참여합니다.
- **부담 없는 기록:** 사진 한 장이면 충분하고, 장소·메모는 선택입니다.
