# UXSSG

UX/UI 프로젝트 작업 저장소입니다. 이 브랜치(`monit-mvp`)는 **MONIT(모닛)** 프로젝트입니다.

## MONIT (모닛)

> **함께한 순간이, 오래 남는 추억이 되도록.**
> 친구들과 놀러간 장소가 지도 위에 **추억 사진 섬네일 마커**로 쌓이는 프라이빗 소셜 라이프로그 서비스

약속을 만들고 친구들과 사진을 함께 모으면, 다녀온 장소가 지도에 사진 섬네일 핀으로 남습니다. 전국을 여행했다면 줌아웃했을 때 지역별로 묶여 보이고, 지역을 누르면 그 안의 장소 핀이 펼쳐집니다.

### 핵심 아이디어

- **약속 기반 기록:** 확정된 약속이 곧 공동 추억 공간이 됩니다.
- **지도 위 추억:** 장소마다 대표 사진이 섬네일 마커로 뜨고, 방문 횟수가 배지로 표시됩니다.
- **프라이빗 기본값:** 초대한 멤버만 볼 수 있고, 호스트 승인 후 참여합니다.
- **부담 없는 기록:** 사진 한 장이면 충분하고, 장소·메모는 선택입니다.

## 우리 사이 — 최종 PRD (v2.0)

> **함께할 날을 정하고, 함께한 시간을 오래도록 남겨요.**
> 친구들과 만남을 정하고, 비용과 사진·이야기를 함께 남기며, 매달 우리의 시간을 한 편의 결산으로 다시 만나는 프라이빗 소셜 라이프로그

전문은 [`우리사이_최종_PRD.md`](우리사이_최종_PRD.md)에 있습니다. 페르소나와 문제 정의는 아직 실제 사용자 조사로 검증되지 않은 가설이며, 구현 전에 기록 담당자와 초대받는 친구 양쪽 인터뷰와 사용성 테스트를 진행합니다.

### 해결하려는 문제

- 사진은 많지만 당시의 대화와 감정은 사라지고, 기억이 단톡방·갤러리·SNS에 흩어집니다.
- 날짜·시간·장소 조율과 모임 비용 확인이 단톡방에서 반복됩니다.
- 기록을 다시 꺼내 볼 계기가 부족하고, 기록 담당자 한 사람에게 부담이 몰립니다.

### 제품 원칙

1. **Private by Default** 초대받아 승인된 멤버만 모임 기록을 봅니다.
2. **One Small Contribution** 사진, 한 줄, 반응 중 하나만 남겨도 참여가 완료됩니다.
3. **Separate Perspectives** 친구들의 서로 다른 기억을 하나의 사실로 합치지 않습니다.
4. **No Lost Work** 네트워크 오류와 앱 종료로 작성 내용이 사라지지 않습니다.
5. **User-Controlled Recall** 보고 싶지 않은 추억과 알림을 사용자가 제외합니다.
6. **Preview Before Sharing** 외부 공유 전에 포함되는 사진·문구·장소를 확인합니다.
7. **No Public Shaming** 콕찌르기와 참여 통계가 압박이나 망신이 되지 않게 합니다.

### 기능 범위와 우선순위

| 우선순위 | 기능 |
|---|---|
| P0 | 계정·초대 수락·모임별 닉네임, 모임 공간과 멤버 권한(Owner·Admin·Member), 여러 사진·이야기 기록(초안 저장·부분 실패 재시도), 공동 코멘트·반응, 사진 달력·최근 기록·상세, 삭제·탈퇴·신고·숨김 |
| P1 | 만남 일정 후보·투표·확정, 비용 기록·정산 요약, 콕찌르기, 월말 결산 포스팅, 단톡방 공유·스토리용 저장, 검색·필터 |
| P2 | 회상 알림, 지도·장소 기반 회상, 일정 캘린더 내보내기 |
| 제외 | 자동 대화 수집·감정 추론, 송금·결제 대행(비용 기록과 요약까지만 제공) |

P1 기능은 다음 P0 출시 게이트를 만족한 뒤 켭니다: 권한 없는 접근 0건, 작성 내용 손실 0건, 초대받은 사용자의 도움 없는 첫 기여, 삭제의 모든 파생 화면 반영, 역할·탈퇴·관리자 이전 정책 구현.

### 핵심 사용자 흐름

> 안전한 초대 → 함께 만날 날 정하기 → 사진과 이야기 남기기 → 친구가 기억 보태기 → 비용 정리 → 월말 결산으로 다시 보기 → 원하는 내용만 공유하기

### 월말 결산과 공유

- 결산은 표지 콜라주, 이달의 숫자, 베스트 순간(반응 수 기준, 동률이면 직접 선택), 모임별 이야기, 코멘트 왕(참여 3명 이상·코멘트 5개 이상일 때만), 다음 달 한마디로 구성합니다.
- 사용자가 입력하지 않은 사실·감정·발언은 만들어내지 않으며, 삭제·숨김 콘텐츠는 자동 제외합니다.
- 공유 전 미리보기에서 포함 항목을 고릅니다. 비용·정확한 장소·닉네임은 기본 제외이고, 외부 공개 링크는 초기 버전에서 제공하지 않습니다.

### 개인정보와 안전

모든 서버 요청에서 모임 권한을 확인하고, 업로드 시 위치 등 EXIF 메타데이터를 제거합니다. 잠금 화면 알림은 일반 문구가 기본이며, 데이터 내려받기와 계정 삭제를 지원합니다.

### 출시 로드맵

| 단계 | 내용 |
|---|---|
| Phase 1 · Trust & Core Memory | 계정·초대·닉네임, 모임 권한, 사진·이야기·코멘트·반응, 달력·최근 기록, 수정·삭제·숨김·신고·탈퇴 |
| Phase 2 · Meet & Organize | 일정 후보·투표·확정, 비용 기록·정산 요약, 콕찌르기, 검색·필터 |
| Phase 3 · Monthly Recall & Share | 월말 결산 생성·편집, 단톡방 공유, 스토리용 이미지 저장 |
| Phase 4 · Long-term Recall | 회상 알림, 지도·장소 기반 탐색, 캘린더 내보내기 |

### 열린 결정

초대 기본값(즉시 참여 vs 승인), 닉네임 변경 제한, 일정 자동 확정 여부, 비용의 사용자 지정 분배·복수 결제자, 탈퇴자 데이터 보존 기간, 코멘트 왕 기본 노출 여부, 결산 이미지의 인물 동의, 외부 공개 링크 설계는 아직 정해지지 않았습니다.
