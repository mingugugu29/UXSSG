# MONIT (모닛)

> **함께한 순간이, 오래 남는 추억이 되도록.**
> 친구들과 놀러간 장소가 지도 위에 **추억 사진 섬네일 마커**로 쌓이는 프라이빗 소셜 라이프로그 서비스

약속을 만들고, 친구들과 사진을 함께 모으면, 다녀온 장소가 지도에 사진 섬네일 핀으로 남습니다.
전국을 여행했다면 줌아웃했을 때 지역별로 묶여 보이고, 지역을 누르면 그 안의 장소 핀이 펼쳐집니다.

## 핵심 아이디어

- **약속 기반 기록:** 확정된 약속이 곧 공동 추억 공간이 됩니다. 별도 앨범을 만들 필요가 없습니다.
- **지도 위 추억:** 장소마다 대표 사진이 섬네일 마커로 뜨고, 같은 장소를 여러 번 가면 방문 횟수가 배지로 표시됩니다.
- **프라이빗 기본값:** 초대한 멤버만 볼 수 있습니다. 링크만으로는 사진이 보이지 않고 호스트 승인 후 참여합니다.
- **부담 없는 기록:** 사진 한 장이면 충분하고, 장소·메모는 선택입니다. 위치 권한 없이도 쓸 수 있습니다.

## 주요 기능 (PRD P0 기준)

| 화면 | 내용 |
|---|---|
| 홈 | 다가오는 약속, 사진을 기다리는 약속, 최근 추억 |
| 추억 지도 | 사진 섬네일 마커, 지역 클러스터(줌인 시 개별 핀), 친구별 필터, 핀을 누르면 장소 시트 |
| 보관함 | 월별 타임라인, 상태 배지(다가오는 약속 · 진행 중 · 추억 · 사진 추가 대기) |
| 약속 상세 | 멤버, 다녀온 장소, 사진 기록, 초대 링크 복사, 본인 사진 삭제 |
| 새 약속 · 사진 추가 | 제목·날짜·장소 선택, 여러 장 업로드, 장소 연결 시 지도에 핀 생성 |

## 디자인

plytoo 디자인 시스템을 따릅니다. 대표색 Violet 500(`#6155F5`), 포인트 Lime 300(`#B9F36B`)·Pink 400(`#F56F98`)이고, 라임·핑크 면 위에는 Violet 900 글자를 올립니다. 타이포·간격·형태 규칙은 원본을 유지합니다.

## 실행

1. `config.example.js`를 `config.js`로 복사하고 Google Maps JavaScript API 키를 입력합니다. (`config.js`는 git에 올라가지 않습니다.)
2. Google Cloud Console에서 키를 HTTP 리퍼러와 Maps JavaScript API로 제한합니다. `localhost`에서 테스트하려면 `http://localhost:8000/*`를 리퍼러에 추가합니다.
3. 프로젝트 폴더에서 실행합니다.

   ```bash
   python3 -m http.server 8000
   ```

4. 브라우저에서 http://localhost:8000 을 엽니다.

`file://`로 직접 열면 리퍼러 제한 때문에 지도가 뜨지 않을 수 있습니다.

## 현재 한계

- 백엔드가 없는 데모입니다. 데이터는 브라우저 localStorage에만 저장되고, 초대 승인과 멤버 동기화는 화면만 있습니다.
- 데모 사진은 picsum 임시 이미지입니다. 직접 올린 사진은 720px로 줄여 저장합니다.
- 사진 EXIF 위치는 읽지 않습니다. PRD 11.3 "사용자 확인 없이 위치를 공개하지 않는다"를 따랐습니다.
- 영상(P1), 이모지 반응, 기간 필터는 구현하지 않았습니다.
- `DEMO_MAP_ID`는 개발용입니다. 운영 전에 Cloud Console에서 만든 Map ID로 교체해야 합니다.
- `design-prototype/`의 지도는 외부 스크립트 제한 때문에 직접 그린 SVG 한반도 지도이며, 사진은 색 타일입니다.
